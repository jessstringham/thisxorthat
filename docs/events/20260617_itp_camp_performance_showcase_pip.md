I did live visuals and built a custom system for this interactive performance.

{% include blog-media.html src="20260617_itp_camp_performance_showcase_pip_pip2.jpeg" layout="float" %}





Members of the audience would approach a camera. The system would classify the facial expressions into eight different emotions. This used MediaPipe to extract features and a small neural network I trained to classify the facial features into emotions.

The live visuals would shift between eight different configurations of the same system that reflected the emotions.

This project was in collaboration with Sasha Solovyeva, Deron Gopie, and Sara Jakubowicz.
