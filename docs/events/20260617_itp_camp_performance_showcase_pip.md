Members of the audience would approach a camera. The system would classify facial expressions into eight different emotions.

This used MediaPipe for features, with a small neural network trained.



The live visuals would shift between eight different configurations of the same system that reflected the emotions.

This project was in collaboration with Sasha Solovyeva, Deron Gopie, and Sara Jakubowicz.
